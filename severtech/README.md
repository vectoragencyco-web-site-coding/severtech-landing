# СЕВЕРТЕХ — прототип лендинга

Откройте index.html или запустите `python3 -m http.server 8000` в корне проекта. Статическая сборка работает без установки пакетов; вместо Tailwind использован обычный CSS.

## Перед публикацией
- Подтвердите все коммерческие обещания, цены, характеристики, сроки, налоговый режим и график работы. Тексты взяты из предоставленного плана, а не проверены.
- Замените телефон, email, реквизиты и часы работы на реальные. Телефон-заглушка намеренно не является активной ссылкой.
- Подготовьте утверждённую юристом политику конфиденциальности и согласие, замените обе страницы в legal/. Текущие страницы — заглушки, не юридические документы.
- Подключите серверный обработчик HTTPS в assets/js/config.js: formEndpoint. Он должен принимать JSON и возвращать 2xx только после реального принятия заявки. Настройте CORS, серверную валидацию, защиту от спама и повторных запросов, обработку персональных данных. Без endpoint заявка не отправляется и показывается понятное сообщение.
- При необходимости подключите аналитику через функцию analytics(name) в config.js. Личные данные в события не передаются.
- Фотография носит иллюстративный характер и не изображает подтверждённый парк компании. Для каталога нужны реальные согласованные фотографии заявленных машин. Фото: https://www.pexels.com/photo/snow-clearing-27306416/ (проверьте условия лицензии перед публикацией).
- Укажите домен, OG-изображение, регион и подтверждённые данные организации. JSON-LD намеренно не добавлен без достоверных данных.
